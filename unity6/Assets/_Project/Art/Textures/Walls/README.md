# Paredes (placeholder procedural)

Generadas por `demo-web/tools/export-assets.mjs` con el mismo código que la demo web
(`demo-web/src/walls.js`), así Unity y la demo pintan sobre las mismas paredes.
Regenerar: `NODE_PATH=$(npm root -g) node demo-web/tools/export-assets.mjs`.

Sustituir por fotografía real (paredes legales, persianas, vagones en depósito) cuando haya arte.
